Device Templates Example

How to Use:

  1. Place device images in static/images/devices/ folder
  2. Use the examples below to create device templates
  3. Click "Load Example Templates" to load the example JSON
  4. Click "Create All Templates" to add them to the database
  5. Or copy individual templates and create them one by one
